# Revenue Desk - Local Business SaaS

## Target Market
Local service businesses (salons, auto repair, plumbers, clinics, consulting)

## Core Features to Build

### Phase 1: Foundation
| Feature | Description |
|---------|-------------|
| **Workspaces** | Each business gets isolated data (multi-tenant) |
| **Auth** | Sign up, login, password reset |
| **Dashboard** | Overview stats (revenue, leads, customers) |

### Phase 2: CRM Core
| Feature | Description |
|---------|-------------|
| **Leads** | Track potential customers, status, source |
| **Customers** | Contact info, history, notes |
| **Notes** | Quick notes on interactions |

### Phase 3: Operations
| Feature | Description |
|---------|-------------|
| **Appointments** | Calendar scheduling with time slots |
| **Invoices** | Create, send, track payment status |
| **Services/Pricing** | List what you offer and prices |

### Phase 4: Polish
| Feature | Description |
|---------|-------------|
| **Staff** | Employee management |
| **Reports** | Revenue, appointments, conversion rates |
| **Settings** | Business profile, branding, preferences |

---

## Business Types to Target First

1. **Salons & Spas** - Appointments + retail (product sales)
2. **Home Services** - Quotes + scheduling (plumbers, electricians)
3. **Consultants** - Invoices + appointments

---

## Why These Features?

- Solves real pain: lost leads, missed appointments, manual invoicing
- Common across many local businesses
- Achievable to build as learning project

---

## What Similar SaaS Offer

- **Close** - CRM focus, outbound sales
- **Nimble** - Contact management, email tracking
- **Plains** - Reviews, engagement for local
- **Omni Pro** - AI automations

**Our angle**: Simple, affordable, all-in-one for small local teams (1-10 people)
